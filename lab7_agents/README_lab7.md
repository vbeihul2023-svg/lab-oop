Файл `poetry.lock` фіксує **точні версії** всіх залежностей проекту. Це гарантує що при встановленні на іншому комп'ютері (`poetry install`) будуть встановлені саме ті самі версії бібліотек, що забезпечує відтворюваність середовища.

### Команди ADK
- `adk create` — створення нового проекту агента
- `adk run` — запуск агента в терміналі

## 8. Workflow агенти

### Sequential Agent — code_pipeline
Виконує підагентів **по порядку**: написання коду → рев'ю → рефакторинг.

Переваги Sequential агента: порядок важливий тому що кожен крок залежить від результату попереднього. Не можна робити рев'ю до написання коду.

**📸 [ВСТАВИТИ СКРІНШОТ: результат code_pipeline]**

### Loop Agent — story_improver
Виконує підагентів **у циклі** до виклику `exit_loop`.

Механізм завершення: агент викликає функцію `exit_loop` яка встановлює `tool_context.actions.escalate = True`, що сигналізує LoopAgent про завершення циклу.

**📸 [ВСТАВИТИ СКРІНШОТ: результат story_improver]**

### Parallel Agent — research_team
Виконує підагентів **одночасно** — три дослідники працюють паралельно.

Переваги паралельного виконання: замість 3x часу виконання отримуємо 1x час, тому що всі три дослідження відбуваються одночасно незалежно один від одного.
